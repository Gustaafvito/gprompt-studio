Aquí tienes TRES opciones para usar la app o compartirla.

OPCIÓN 1 (RECOMENDADA): INSTALADOR
═══════════════════════════════════════════════════════════════════

Archivo: GPromptStudio-Setup-1.0.2.exe  (179 MB)

QUÉ HACE:
  - Asistente de instalación profesional.
  - Muestra la licencia (Apache 2.0) antes de instalar.
  - Crea acceso directo en el menú Inicio.
  - Opcional: acceso directo en el escritorio.
  - Aparece en "Agregar o quitar programas" para desinstalar limpio.
  - Se instala en %LOCALAPPDATA% — NO pide permisos de administrador.
  - Si venías de la 1.0.1, borra la carpeta _internal que dejó
    aquella versión (unos 180 MB que ya no sirven).

CÓMO USAR:
  1. Doble-click en GPromptStudio-Setup-1.0.2.exe
  2. Acepta la advertencia de Windows SmartScreen
     ("Más info" → "Ejecutar de todas formas")
     [Normal en programas sin certificado de firma. Ver más abajo.]
  3. Sigue el asistente: Siguiente → Instalar → Finalizar
  4. Lanza desde el menú Inicio o desde el escritorio.

TARDA UNOS SEGUNDOS EN ABRIR, Y ES NORMAL:
  Desde la 1.0.2 el programa va en un único ejecutable que se
  descomprime en una carpeta temporal en cada arranque. Son 4-5
  segundos la primera vez. No está colgado.

  El motivo es serio: la 1.0.1 instalaba el programa repartido en
  una carpeta, y a ese ejecutable Windows Defender lo confundía con
  malware y lo BORRABA después de instalarlo. Empaquetado así ya no
  ocurre. Se cambió velocidad de arranque por que la aplicación siga
  existiendo, y se volverá atrás en cuanto Microsoft corrija su
  detección.

CÓMO COMPARTIR:
  Sube este archivo a Google Drive / WeTransfer / Mega (no cabe por
  email). El receptor solo necesita este .exe, nada más.


OPCIÓN 2: PORTABLE (un solo .exe, sin instalar)
═══════════════════════════════════════════════════════════════════

Archivo: GPromptStudio-Portable-Onefile.exe  (186 MB)

QUÉ HACE:
  - TODO en un único .exe. Sin instalación ni carpetas.
  - Es el mismo programa que instala la Opción 1.
  - Borrando el .exe lo desinstalas del todo.
  - Tarda lo mismo en abrir: 4-5 segundos.

CÓMO USAR:

CÓMO COMPARTIR:
  Es el más cómodo de enviar: un solo archivo, nada que descomprimir.


SOBRE LA ADVERTENCIA DE WINDOWS (SmartScreen)
═══════════════════════════════════════════════════════════════════

  Al abrir cualquiera de las dos opciones, Windows mostrará una
  pantalla azul: "Windows protegió su PC". Es ESPERADO.

  Ocurre porque el ejecutable no está firmado con un certificado de
  firma de código (cuestan 200-400 €/año). No dice nada sobre si el
  programa es seguro: dice que Windows no conoce a quien lo firma.

  PARA ABRIRLO:
    "Más información"  →  "Ejecutar de todas formas"

  Si quieres verificar por tu cuenta que el archivo que has recibido
  es el original y no está manipulado, compara su hash SHA-256 con el
  publicado en la página de descarga. En PowerShell:

    Get-FileHash .\GPromptStudio-Setup-1.0.2.exe -Algorithm SHA256

  Estos son los de esta versión (partidos en dos líneas por el
  ancho; al comprobar, júntalos):

    da63460f6ca202638c7b60b0ed205f47
    a29b11755ecb423d54c383f66e26effb   GPromptStudio-Setup-1.0.2.exe

    614fcb74a646c52d2ec3a416e8e6e910
    45087647ec84d7254f2e0d682d1850cc   GPromptStudio-Portable-Onefile.exe

  ANALIZADO EN VIRUSTOTAL, y el resultado entero:
    - Opción 1, el instalador ..... 0 de 67. Limpio.
    - Opción 2, el onefile ........ 1 de 66: Bkav Pro.

  Microsoft Defender no marca ninguno de los dos.

  Esa única detección de Bkav Pro es "W32.Malware.62456B6B", una
  etiqueta genérica derivada del propio fichero: no nombra ningún
  malware conocido.

  Lo que molesta es el EMPAQUETADO, no el programa. Estos ejecutables
  se construyen con PyInstaller, y su componente de arranque es el
  mismo que usan muchas muestras de malware reales: los antivirus
  reconocen ese componente, no el código.

  En la versión 1.0.1 eso tuvo consecuencias de verdad: Windows
  Defender BORRABA el programa después de instalarlo. Por eso la 1.0.2
  se empaqueta de otra forma, con la que Microsoft no lo marca.

  Si aun así tu antivirus se queja, compara el hash: si coincide con
  el publicado, el fichero es exactamente el que se publicó.


SOBRE SEGURIDAD Y PRIVACIDAD
═══════════════════════════════════════════════════════════════════

  ✓ NINGUNA API key del autor viaja en este paquete. Verificado
    sobre los artefactos reales, no sobre la intención: se buscan
    los prefijos de todos los proveedores (sk-proj-, sk-ant-, xai-,
    pplx-, gsk_, AIzaSy...) y los nombres keys.json, .env y
    .encryption_salt. Resultado: limpio en los tres artefactos.
  ✓ Las keys que metas TÚ se guardan cifradas en:
    - Windows Credential Manager (recomendado, gestor del SO)
    - keys.json cifrado con DPAPI de Windows (fallback en
      %USERPROFILE%\.arquitecto_prompts — solo tu usuario de Windows
      puede descifrarlo)
  ✓ Las dependencias del .exe pasan una auditoría de CVEs conocidos
    (pip-audit) en cada build.
  ✓ La app NO envía datos a ningún servidor del autor.
  ✓ Solo se comunica con los proveedores de LLM que tú configures.

  Pollinations.ai (previews de imagen en el comparador 👁) es
  OPCIONAL. Sin key funciona en modo anónimo (más lento, con
  rate limit). Si quieres velocidad sin cola, regístrate gratis
  en pollinations.ai → API → "+ API Key" y pégala desde:
    Header → 🔑 API Keys → sección "🖼 Proveedores de IMAGEN"
  CADA USUARIO usa su propia key — el autor NO se hace cargo del
  coste de tu cuenta. ~555 imágenes flux por 1€ (1 Pollen).


PRIMER ARRANQUE
═══════════════════════════════════════════════════════════════════

  Al abrir por primera vez verás todos los proveedores como
  "⚠️ sin configurar". Tendrás que añadir TU PROPIA API key desde:

  Header → 🔑 API Keys (o desde el menú de proveedores)

  Tienes botones "🌐 Obtener key" que abren la web de cada proveedor
  donde puedes generar tu clave gratuita o de pago.

  💡 PARA EMPEZAR GRATIS Y SIN TARJETA: Gemini (Google) y Groq
  regalan API key con límites generosos — con una de las dos la app
  funciona al completo. Groq es además el más rápido de todos los
  proveedores soportados (respuestas en menos de un segundo).

  Los ONCE proveedores de la app se verificaron uno a uno con keys
  reales el 08-sep-2026: catálogo en vivo y una llamada de verdad a
  cada modelo del desplegable. Si un modelo desaparece del catálogo
  de su proveedor, la app lo oculta sola en el siguiente arranque.

  SI USAS COMFYUI: no hay que configurar nada. La app busca la
  carpeta de ComfyUI en las rutas habituales de tus discos fijos,
  detecta tus checkpoints y los agrupa por familia (SDXL, Flux,
  SD 1.5, Pony, Illustrious, Qwen, Z-Image...) para inyectar las
  reglas de prompt correctas a cada uno. Si la tienes en un sitio
  raro, pégale la ruta en Ajustes.

  IDIOMA: la interfaz es bilingüe español/inglés. Se detecta el
  idioma de Windows en el primer arranque; puedes cambiarlo en
  menú UI → 🌐 Idioma (se aplica al reiniciar la app).


TRUCOS PARA EMPEZAR
═══════════════════════════════════════════════════════════════════

  ⌨ Ctrl+K  → Paleta de comandos: escribe lo que buscas ("negative",
              "avatar", "backup"...) y ejecuta cualquier herramienta
              sin bucear por los menús. El mejor atajo de la app.
  ⌨ Ctrl+?  → Lista completa de atajos de teclado.
  ⌨ Ctrl+T  → Tutorial interactivo paso a paso.
  🏠 Menú UI → Dashboard: reto del día, tips y acceso rápido a todo.


REQUISITOS DEL SISTEMA
═══════════════════════════════════════════════════════════════════

  - Windows 10 / 11 (64-bit)
